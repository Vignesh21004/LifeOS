# LifeOS 🚀

A polished, interactive frontend prototype for a **Personal Operating System**.

## What is included

- Responsive dashboard with dark/light mode
- Interactive task management
- Calendar view
- Finance dashboard
- Document vault UI
- Smart reminders
- Analytics view
- LifeOS AI assistant mock interaction
- Search across tasks
- Toast notifications and modal quick-capture
- Modern SaaS-style visual system

## Run locally

```bash
npm install
npm run dev
```

Open the local Vite URL shown in the terminal.
